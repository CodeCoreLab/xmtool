## 四、界面文案缺陷修复记录（本轮新增）

原程序在 8 处属性值上带了**尾随空格**，经原始 BAML 字节取证确认是**原作者编译进程序的真实缺陷**（不是反编译产物）：

| 文件:行 | 原文 | 危害 |
|---|---|---|
| `Views\MainWindow.xaml:2` | `Title="小马远程桌面  "` | 窗口标题带 2 空格 → 任务栏 / 任务管理器可见 |
| `Views\LoginWindow.xaml:2` | `Title="小马远程桌面  "` | 同上 |
| `Views\MainWindow.xaml:235` | `Text="小马远程桌面  "` | 标题栏品牌文字 |
| `Views\AboutWindow.xaml:21` | `Text="小马远程桌面  "` | 关于框品牌文字 |
| `Views\AboutWindow.xaml:45` | `Text="马欣 "` | 作者署名 |
| `Views\AboutWindow.xaml:47` | `Text="© 2026 MIT开源协议     "` | 版权行（表述亦不规范） |
| `Views\MainWindow.xaml:254` | `<Run Text="本机远程桌面 " />` | `<Run>` 尾空格 + Run 间空白 → 渲染双空格 |
| `Views\MainWindow.xaml:601` | `<Run Text="监听 " />` | 同上 |

**取证方法**：BAML 字符串以 7-bit varint 长度前缀编码。`小马远程桌面` 字面量 18 字节（6 汉字 × 3），实测前缀 `0x14` = 20 → 差 2 字节正是两个空格；`马欣` 6 / 前缀 7、`MIT开源协议` 串 15 / 前缀 32 同理。

**WPF 语义旁证**：`<Run Text="A "/> <Run Text="B"/>` 渲染 `A  B`（双空格），`<Run Text="A"/> <Run Text="B"/>` 渲染 `A B`（单空格）——故只去 `Run` 内尾空格即得正确单空格。

**修复后实机验证**：`MainWindowTitle` 由 `[小马远程桌面  ]` 变为 `[小马远程桌面]`（`len=6`）。

## 五、凭据面复核（重构后的当前状态）

重构过程本身已消除一类**高敏感**线索：

| 项 | 重构前 | 重构后 |
|---|---|---|
| 连接密码传递 | `cmdkey.exe /generic:TERMSRV/<host> /user:<u> /pass:<明文密码>` → **明文进命令行，任务管理器「命令行」列可直接看到** | `CredentialStore.cs` 走 Windows 凭据管理器 API（`CredWriteW` / `CredReadW` / `CredDeleteW`），密码只进 `CredentialBlob`（UTF-16LE），不经命令行 |
| 数据文件 | `data.db`（SQLite）与程序同目录，内含加密后的密码列 | 同结构，加密不变；`.gitignore` 已排除 `data.db`，不入库；发布包内亦不含 `data.db` |
| 源码中硬编码密钥 | 无 | 无（`master.key.salt` / `master.key.verifier` 运行时经 `Settings` 表生成） |

**实机验证证据**：反射调用 `CredentialStore.WriteGeneric("TERMSRV/rdpp-verify-probe.invalid", "probeuser", "PROBE-SECRET-123")` 返回 `True`；`CredReadW` 探针读回 `user=[probeuser] blobLen=32 persist=2`；`DeleteGeneric` 两次调用均返回 `True`（第二次命中 `ERROR_NOT_FOUND=1168`，按幂等处理），复读 `err=1168` 确认无残留。

> `data.db` 是**运行时**产物（`AppContext.BaseDirectory\data.db`）。若曾把带真实连接记录的 `data.db` 一并分发过，需另行提醒清除。

## 七、发布前复核命令

复制到 PowerShell 执行，应**仅剩 0 命中**（署名已判定保留，复查时可只关注前 4 项）：

```powershell
$g = "E:\DSH-workspace\rdpp_extract\proj"
Select-String -Path "$g\*.cs","$g\**\*.cs","$g\**\*.xaml","$g\*.csproj","$g\*.md" `
  -Pattern 'maxin|C:\\Users|BaiduNetdisk|github\.com|gitee\.com|@qq\.com|@163\.com' `

# 尾随空格缺陷复查（应 0 命中）
& "C:\Python312\python.exe" -c @"
import pathlib, re
root = pathlib.Path(r'$g')
pat = re.compile(r'(?:Text|Title|Content|Header|Tag)=\"([^\"]*)\"')
n = 0
for p in sorted(root.rglob('*.xaml')):
    if '\\bin\\' in str(p) or '\\obj\\' in str(p): continue
    for i, line in enumerate(p.read_text(encoding='utf-8').split('\n'), 1):
        for m in pat.finditer(line):
            v = m.group(1)
            if v != v.rstrip():
                n += 1; print(f'{p.relative_to(root)}:{i}  {m.group(0)!r}')
print('尾随空格命中数 =', n)
"@
```
