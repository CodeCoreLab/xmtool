小马远程桌面

远程主机的批量管理长期存在三类问题： 记录散落于文本文件、凭据以明文存放、可达性需逐台手动验证。

  • 连接管理：主机、端口、账号与排序位统一持久化，于一列表内完成增删改查与拖拽排序。
  • 凭据加密：记录级独立密文，支持本机 DPAPI 与主密码 AES-256-GCM 双形态切换。
  • 批量探活：并发 TCP 探测替代逐台手动验证，20 路限流规避连接风暴。
  • 服务管理：本机远程桌面开关与端口变更，同步维护防火墙入站规则。

不联网、不上云、无服务端，数据始终留存于本机。

产品概览

将分散的主机资产，收敛为一份可维护的清单

远程主机的日常管理通常依赖记事本、电子表格或人工记忆：凭据以明文散落存放， 可达性需逐台手动尝试确认，端口变更亦缺少可追溯记录。 本产品以单库持久化与记录级加密为基础，将连接清单、凭据存储与状态探测统一结构化。

  • 清单可维护：主机、端口、账号与排序位统一落库，支持拖拽排序与事务内批量写回。
  • 凭据可加密：记录级独立密文，DPAPI 与主密码双形态可按需逐条切换。
  • 状态可探测：一键并发探活，替代逐台手动试连。

程序启动时读取同目录下的 data.db（首次运行自动建表）。连接清单、应用选项与安全设置均持久化于该单一数据库，拖拽排序、双击直连与状态标注在同一列表视图中完成。

凭据不以明文入库：单机场景采用 Windows DPAPI，跨机器迁移时切换为主密码派生的 AES-256-GCM。发起连接时密码不经过任何命令行参数，而是写入系统凭据管理器。

程序常驻系统托盘，关闭窗口即隐藏而非退出；全局单实例运行，重复启动时将已有窗口置于前台。

凭据散落 → 记录级加密，DPAPI / AES-256-GCM 双形态按需切换
状态不明 → 并发 TCP 探活，单条 1.5s 超时，20 路并发限流
端口无据 → 读写注册表 PortNumber，同步维护防火墙入站规则
迁移困难 → 整库导出 / 导入，导出采用 VACUUM INTO 生成一致快照
无人值守 → 托盘常驻 + 启动密码保护，最小化即隐藏

连接记录管理

主机、端口、账号、备注与排序位统一持久化。支持增删改查、拖拽排序（事务内批量写回）与双击直连，操作集中于单一列表视图。

事务写入保障排序不丢失

凭据双形态加密

每条记录独立加密，密文前缀标识来源：D1$ 为本机 DPAPI 形态，M1$ 为主密码 AES-256-GCM 形态。切换主密码时全量重加密，任一环节失败则整体回滚。

前缀即来源，双形态可混合共存

批量在线检测

对全部记录执行并发 TCP 探活，单条超时 1.5 秒，以 20 路并发限流规避连接风暴。检测期间操作按钮自动禁用，防止重复触发。

探活失败统一静默返回，不抛异常

本机 RDP 服务管理

一键开关本机远程桌面、修改监听端口，并同步维护 Windows 防火墙入站规则；变更可一键还原。

权限不足时抛出明确异常，不静默失败

凭据加密

两种密文形态，各自解决一个问题

1DPAPI 形态（D1$）密文绑定当前 Windows 用户，无法在其他机器上解密。零配置，适用于单机长期使用。
2主密码形态（M1$）以 PBKDF2-SHA256 迭代 20 万次派生 32 字节密钥，采用 AES-256-GCM 加密。设置主密码后整库可跨机器迁移，凭密文与主密码即可解密。
3切换即全量重加密设置或移除主密码时，于事务内重写全部记录。任一环节失败则数据库与内存对象同步回滚，不会残留部分更新状态。
4单列写入，不重写整行重加密采用单列 UPDATE，仅修改 Password 字段，其余 6 列不参与写入，规避全表写放大。
// 旧做法（已替换）：密码出现在进程命令行

连接安全

密码不进进程命令行

1规避 cmdkey 命令行传参直接调用凭据管理器 API 写入通用凭据，调用参数中不含密码，任务管理器与 CommandLine 查询均不可见。
2连接参数经文件传递分辨率、本地盘重定向与控制台模式等选项写入临时 .rdp 文件（UTF-16LE 编码），客户端仅接收文件路径。
3用后即清连接建立 5 秒后延迟清理临时文件与一次性凭据；程序启动时同步清扫上次残留的 .rdp 文件。
4凭据修复入口连接异常时可通过右键菜单「修复凭证」清除旧凭据，下次连接时重新写入。

各项能力对应的具体问题与解决方式

对比基准为「手工记录 + 手动执行 mstsc」这一常见做法， 而非虚构竞品；以下逐项说明能力差异与实现方式。

凭据加密

记录级密文配合自解释前缀：单机场景可直接采用 DPAPI 形态，无需额外配置；需要迁移时切换为主密码形态。两种形态可在同一数据库内逐条共存。

密文 = 前缀 + Base64( nonce(12) ‖ tag(16) ‖ cipher )
D1$ 本机绑定 / M1$ 可跨机迁移

启动密码

以 PBKDF2-SHA256 迭代 20 万次派生校验值，比对采用定长时间函数（防时序侧信道攻击）。连续 5 次验证失败后程序自动退出，不提供无限试错窗口。

verify = FixedTimeEquals( Pbkdf2(pw, salt, 200000) , stored )
定时安全比较 + 失败上限 5 次

在线检测

采用纯 TCP 连通性探测，不依赖 RDP 协议握手，因此对未登录或服务异常的主机同样有效。失败路径统一静默返回，界面不因单台异常而中断整批扫描。

并发 = SemaphoreSlim(20) , 单条超时 = 1500ms
限流防连接风暴 + 扫描期按钮自锁

备份与迁移

导出采用 VACUUM INTO，由 SQLite 引擎内部生成一致快照，规避拷贝与写入并发导致的文件不一致；导入前校验 SQLite 文件头，拒绝任意文件覆盖数据库。

典型使用场景与角色说明

本产品定位于长期沉淀主机访问入口的日常工具，而非一次性临时使用， 以下按角色说明典型用法。

多环境凭据隔离

  • 生产库主机凭据独立加密存放，不与测试环境混用
